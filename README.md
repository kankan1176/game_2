# 翡翠荘の甘き密室

16人の視点を切り替え、30回の対話と証拠照合でタルト消失の謎を解くHTML推理ゲームの試遊版です。

## 起動

Node.js 24で検証済み。外部パッケージのインストールは不要です。

```sh
npm start
```

起動後、ブラウザで http://127.0.0.1:4175 を開きます。

## 検証

```sh
npm test
```

ゲームと素材は `dist/` にあります。人物は名前のみ表示。具体的なセリフ選択、会話による相性の発見、手帳での証拠照合、任意ヒント、自動保存に対応しています。音は初期OFFです。

目標プレイ時間は1〜2時間ですが、長時間試遊と難易度評価は未実施です。制作資料は収録していません。ブラウザで動くゲームのコードには判定と真相が含まれます。

GitHub PagesなどのWeb配信設定はまだ行っていません。
